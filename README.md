# For Sanjana 💗

A romantic, interactive birthday experience made by Baldeep Singh for Sanjana Bhola (29 October 2001).

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Streamlit will show a local URL (usually `http://localhost:8501`).

## Deploy on Streamlit Community Cloud

1. Upload `app.py` and `requirements.txt` to a new public GitHub repository.
2. Go to https://share.streamlit.io/ and select **Create app**.
3. Choose the repository, branch, and `app.py` as the main file.
4. Deploy, copy the app link, and send it to Sanjana at midnight. 💗

For the best experience, ask her to open the link on her phone and tap through the birthday surprises.

The app uses Google Fonts (with browser fallback fonts) and needs no images, API keys, or other assets.
